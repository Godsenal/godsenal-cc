## 2. 패턴: 댓글을 받으면서 신뢰를 지키는 자료, 역효과 나는 자료

**신뢰를 지키는 쪽**
- **공개 자료실 + DM은 편의.** 에트([자료실](https://aitrend-library.pages.dev/)), 프롬왓([자료실](https://promptwhat-ai-library.promptwhatt.chatgpt.site/)), 에브리AI([DM 허브](https://every-ai-guides.vercel.app/dm)), 지후([가이드](https://zihu-guide.pages.dev/guides/)), 에이아이프릭스 모두 DM이 안 와도 프로필 링크에서 같은 자료를 받을 수 있게 해 뒀어요. 댓글을 안 달면 못 받는 구조가 아니에요.
- **단계형 + 복붙 + 확인법.** 좋았던 자료(지후 100개 코드, 에트 치트키 50, 에브리 k-skill)에는 공통으로 ① 준비물, ② STEP, ③ 복붙 프롬프트 블록, ④ "확인할 것/안 될 때"가 있었어요. 분량은 웹 한 페이지에 3,000~5,000자였어요.
- **직접 돌려 봤다는 표시와 한계 문구.** "✅ 직접 돌려 본 명령어", "테스트에서 보낸 문장 그대로", "숨은 공식 기능이 아니라", "재확인하지 못했습니다" 같은 문장이에요. 과장 의심을 먼저 막아 줘요.
- **약속과 자료가 1:1.** "설치법 + 분야별 질문 예시"(에브리)처럼 장에 쓴 말이 자료 목차와 그대로 맞아요.

## 3. @haedollar 적용안

**원칙**
1. 자료는 게시 전에 완성해 공개 자료실에 먼저 올려요.
2. DM은 그 링크를 보내는 편의 수단일 뿐이에요.
3. 팔로우나 공유 조건은 걸지 않아요.
4. 장에 쓴 약속(개수·내용)은 자료 목차와 글자 그대로 맞춰요.

**글 종류별 자료 형태**

| 글 종류 | 줄 자료 | 분량 | 넣는 빈도 |

| AI 뉴스 | "한 장 정리 + 풀리면 확인할 것" 체크리스트. 캐러셀에 없는 정보(전체 비교표, 가격 계산, 확인 포인트)가 있을 때만 넣어요. | 1,500~2,000자 | 선택. 없으면 기존 팔로우 2장 그대로 |

**Claude Code 제작 방식 (글 1편당 자료 1개)**
1. 캐러셀 조사 폴더(공식 원문 txt, 숫자 표)를 그대로 입력으로 써요. 자료에 들어가는 숫자도 캐러셀과 똑같이 원문과 대조해서 작업 폴더 report에 남겨요.
2. `reward/<slug>.md`를 정해진 틀(요약 → 준비물 → STEP/표 → 확인할 것 → 한계)로 작성해요.
3. 팁 자료는 Claude Code가 프롬프트를 실제로 한 번씩 돌려 결과를 캡처해요. 돌려 보지 못한 항목에는 ✅를 붙이지 않아요.
4. 정적 사이트로 빌드하고 배포해요. 모바일에서 열어 보고 복사 버튼, 표, 링크가 되는지 확인해요.
5. 장 문구(키워드 + 받는 것)와 자동 DM 문구를 같은 run에서 만들어요.

예상 소요 시간: 팁 자료 40~60분(직접 실행 포함), 뉴스·돈 자료 20~30분.

**보관 위치 제안**
- **1순위: 정적 자료실 사이트(GitHub Pages나 Cloudflare Pages, `haedollar` 자료실).** 에트(pages.dev), 에브리(vercel.app), 지후(pages.dev)가 같은 방식을 써요. Claude Code가 마크다운에서 바로 배포할 수 있고, 게시물별 URL과 "DM 못 받았다면" 목록 페이지를 자동으로 만들 수 있어요.

**장 위치:** 보상 장이 지금의 '팔로우 1' 장 자리(끝 장 바로 앞)에 들어가고, 마지막 '팔로우 카드'는 그대로 둬요. 보상 장의 틀은 무드모드 6장(흐린 자료 미리보기 + 흰 박스 3줄: 행동 → 받는 것 → 결과)을 따라요.
